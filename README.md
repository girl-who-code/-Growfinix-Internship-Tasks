# Customer Segmentation Using Unsupervised Learning

## Project Overview
This project implements customer segmentation using unsupervised machine learning techniques.

The objective is to identify hidden customer groups based on customer behavior and purchasing patterns.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- K-Means Clustering
- DBSCAN
- Plotly
- Google Colab

## Dataset
The dataset contains 1000 synthetic customer records with the following attributes:
- Customer ID
- Age
- Annual Income
- Browsing Time
- Enquiry Frequency
- Purchase Frequency
- Spending Score

## Algorithms Implemented
1. K-Means Clustering
2. DBSCAN Clustering

## Visualization
Interactive 3D visualizations using Plotly to display customer clusters.

## Project Results
- Customer segmentation into different groups.
- Identification of customer behavior patterns.
- Detection of noise and outliers using DBSCAN.
- Marketing strategy recommendations.

## How to Run
1. Download the Customer_Segmentation.ipynb file.
2. Open Google Colab.
3. Upload the notebook.
4. Upload the dataset if required.
5. Run all cells.
